# 0010 — Android Gradle Plugin fissato (ora 9.x)

- **Stato**: accettata; aggiornata il 2026-11-26 da AGP 8.13 ad AGP 9.5
- **Data**: 2026-11-26

## Contesto

All'inizio il progetto usava AGP 8.13.2 + Gradle 8.14.3 + compileSdk 36, per evitare il cambio di
DSL di AGP 9. Con il lettore nativo (decisione 0015) servono librerie recenti (Compose 1.12+,
OkHttp 5.5+, androidx.core 1.19+) che richiedono **compileSdk 37 e AGP 9**: con AGP 8 le PR di
Dependabot fallivano al controllo `checkReleaseAarMetadata`.

## Decisione

AGP 9.5.3 + Gradle 9.9.2 (AGP 9.5 vuole Gradle 9.6 o successivo) + compileSdk 37, con il
"Kotlin integrato" di AGP 9 (il modulo non applica più `org.jetbrains.kotlin.android`; la radice
lo dichiara solo per fissarne la versione). `targetSdk` resta 36 finché l'app non è provata su
Android 17. Build script con la sintassi di assegnazione (`minSdk = 24`), valida per il nuovo DSL.

## Conseguenze

- Per aggiornare l'AGP cambia insieme `android/build.gradle` e `gradle-version` in
  `.github/workflows/android.yml`, in una PR (il workflow Android gira sulle PR).
- Dependabot ignora solo i major dell'AGP (il prossimo sarà la 10).
- Il nome del file resta `0010-agp-8.md` perché altri documenti lo collegano.
