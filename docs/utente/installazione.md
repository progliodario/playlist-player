# Installare l'app

Indirizzo dell'app: **https://progliodario.github.io/playlist-player/**

L'app funziona anche senza installarla, direttamente nel browser. Installarla aggiunge
un'icona e la apre in una finestra propria, senza barre del browser.

## Windows 10/11

1. Apri l'indirizzo con **Microsoft Edge** o **Google Chrome**.
2. Edge: menu `⋯` → **App** → **Installa questo sito come app**.
   Chrome: icona "Installa" a destra nella barra degli indirizzi, oppure menu `⋮` →
   **Trasmetti, salva e condividi** → **Installa pagina come app**.
3. L'app compare nel menu Start e si può fissare alla barra delle applicazioni.

In alternativa, dentro l'app: **Impostazioni** → **Installa l'app** → **Installa** (se il browser
lo consente).

- Aggiornamenti: automatici, alla successiva apertura.
- Disinstallare: Start → clic destro sull'app → **Disinstalla**.

## Android

### Con l'APK (consigliato)

1. Dal telefono apri <https://github.com/progliodario/playlist-player/releases/latest>.
2. Scarica il file `playlist-player-X.Y.Z.apk`.
3. Aprilo dalle notifiche o dall'app **File** → consenti "Installa app sconosciute" per il browser
   se richiesto → **Installa**.
4. Serve **Google Chrome** installato (l'app usa Chrome per mostrarsi a schermo intero).
   Android 7.0 o successivo.

> L'app Android apre sempre la versione più recente: non serve reinstallare l'APK per avere le
> novità. Va aggiornata solo quando una nuova Release lo indica.

### Senza APK

Apri l'indirizzo con Chrome → menu `⋮` → **Installa app** (o **Aggiungi a schermata Home**).
