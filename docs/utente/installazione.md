# Installare l'app

Indirizzo dell'app: **https://progliodario.github.io/playlist-player/**

## Windows 10/11

1. Apri l'indirizzo con **Microsoft Edge** o **Google Chrome**.
2. Edge: menu `⋯` → **App** → **Installa questo sito come app**.
   Chrome: icona "Installa" a destra nella barra degli indirizzi, oppure menu `⋮` → **Trasmetti,
   salva e condividi** → **Installa pagina come app**.
3. L'app compare nel menu Start e si può fissare alla barra delle applicazioni. Si apre in una
   finestra propria, senza barre del browser.

In alternativa, dentro l'app: **Impostazioni** → **Installa** (se il browser lo consente).

Aggiornamenti: automatici (alla successiva apertura).
Disinstallare: Start → clic destro sull'app → **Disinstalla**.

## Android

### Con l'APK (consigliato)

1. Apri <https://github.com/progliodario/playlist-player/releases/latest> dal telefono.
2. Scarica `playlist-player-X.Y.Z.apk`.
3. Aprilo dalle notifiche o da **File** → consenti "Installa app sconosciute" per il browser se
   richiesto → **Installa**.
4. Serve **Google Chrome** installato (l'app usa Chrome per mostrare la pagina a schermo intero).

> L'app Android apre sempre la versione più recente del sito: non serve reinstallare l'APK per
> avere le novità. Va aggiornato solo quando esce una nuova Release con cambiamenti all'APK.

### Senza APK

Apri l'indirizzo con Chrome → menu `⋮` → **Installa app** (o **Aggiungi a schermata Home**).

## Note

- Per l'audio a schermo spento: il player di YouTube deve restare visibile (regole di YouTube),
  quindi con lo schermo bloccato la riproduzione può fermarsi.
- L'accesso con Google è facoltativo: [GOOGLE-OAUTH-SETUP.md](GOOGLE-OAUTH-SETUP.md).
